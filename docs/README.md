# Documentation Hub

This repository follows a docs-first workflow: document intent and requirements before implementing code.

## Structure
- `product/`: goals, requirements, and scope.
- `domain/`: domain models and flow specs.
- `engineering/`: architecture and integration contracts.
- `decisions/`: ADRs.
- `templates/`: reusable authoring templates.
- `releases/`: release notes.
- `incidents/`: incident postmortems.
- `roadmap/`: forward-looking proposals.

## Docs-First Rules
1. Start every feature/change with docs updates in this folder.
2. Link affected docs in each implementation PR.
3. If docs are not required, provide explicit rationale in PR.
